# ShopKart Backend

ShopKart Backend is a RESTful API for an e-commerce web application.

## 🚀 Features
- User authentication (Login/Register)
- Product management
- Cart system
- Order management
- REST API architecture

## 🛠️ Tech Stack
- Node.js
- Express.js
- MongoDB
- JWT Authentication

## 📦 Installation

```bash
git clone https://github.com/deepikas19998-art/ShopKart-Backend.git
cd ShopKart-Backend
npm install
